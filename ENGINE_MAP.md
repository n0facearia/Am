## 2. Server & Engine Locations

The server and session coordination layers are structured as follows:
*   **HTTP Server / Endpoints:** The server API is defined in [`packages/server/src`](file:///home/n0face/Documents/Vscode%20projects/Am-Project/packages/server/src), with handler functions in [`packages/server/src/handlers/`](file:///home/n0face/Documents/Vscode%20projects/Am-Project/packages/server/src/handlers).
*   **Session Coordination / Engine Loops:** The agent execution loop, coordinator state, and session runner live under [`packages/core/src/session/`](file:///home/n0face/Documents/Vscode%20projects/Am-Project/packages/core/src/session).
    *   [`runner/index.ts`](file:///home/n0face/Documents/Vscode%20projects/Am-Project/packages/core/src/session/runner/index.ts): Coordinates agent steps, model execution, tool invocation, and history updates.
    *   [`execution/local.ts`](file:///home/n0face/Documents/Vscode%20projects/Am-Project/packages/core/src/session/execution/local.ts) and [`run-coordinator.ts`](file:///home/n0face/Documents/Vscode%20projects/Am-Project/packages/core/src/session/run-coordinator.ts): Manages process-local session ownership and wakes.
    *   [`sql.ts`](file:///home/n0face/Documents/Vscode%20projects/Am-Project/packages/core/src/session/sql.ts): SQLite database adapter utilizing Drizzle ORM for durable persistence.

## 3. Terminal UI (TUI) Location

*   **TUI Package:** Located in [`packages/tui`](file:///home/n0face/Documents/Vscode%20projects/Am-Project/packages/tui).
*   **Framework & Components:** Built with SolidJS, styling primitives, and custom terminal libraries (`@opentui/solid`, `@opentui/core`).
*   **Main Application Screen:** The central routing view for active session logs, chats, and action confirmations is located at [`packages/tui/src/routes/session/index.tsx`](file:///home/n0face/Documents/Vscode%20projects/Am-Project/packages/tui/src/routes/session/index.tsx).
*   **Theme Integration:** TUI color definitions and styling rules are processed under [`packages/tui/src/theme/index.ts`](file:///home/n0face/Documents/Vscode%20projects/Am-Project/packages/tui/src/theme/index.ts).

## 4. Built-in Agent Definitions

*   **Registry & Configuration:** The primary built-in agents and subagents are defined and registered within [`packages/core/src/plugin/agent.ts`](file:///home/n0face/Documents/Vscode%20projects/Am-Project/packages/core/src/plugin/agent.ts).
    *   `build`: Registered via `AgentV2.defaultID` (resolving to `"build"`) with default coding/editing guidelines.
    *   `plan`: Registered as `"plan"` agent mode with editing tools restricted, except for `.opencode/plans/*.md` editing.
    *   `general`: Registered as a subagent helper for general research tasks.

## 5. Configuration & Theme Configurations

*   **Default Configuration Engine:** Parsing, validation, and migration of configuration files (`opencode.json`, `opencode.jsonc`) is handled in [`packages/core/src/config.ts`](file:///home/n0face/Documents/Vscode%20projects/Am-Project/packages/core/src/config.ts) using schemas under [`packages/core/src/config/`](file:///home/n0face/Documents/Vscode%20projects/Am-Project/packages/core/src/config).
*   **Themes / Color Palettes:** Defined in JSON format under [`packages/tui/src/theme/assets/`](file:///home/n0face/Documents/Vscode%20projects/Am-Project/packages/tui/src/theme/assets/) (e.g. `opencode.json`, `tokyonight.json`, `dracula.json`) and imported/resolved in [`packages/tui/src/theme/index.ts`](file:///home/n0face/Documents/Vscode%20projects/Am-Project/packages/tui/src/theme/index.ts).

## 6. CLI Entry Points & Dev Scripts

*   **CLI Entry Points:**
    *   Development Entry Point: [`packages/opencode/src/index.ts`](file:///home/n0face/Documents/Vscode%20projects/Am-Project/packages/opencode/src/index.ts) (uses `yargs` to define and map terminal commands).
    *   Command-line Wrapper Binary: [`packages/opencode/bin/opencode`](file:///home/n0face/Documents/Vscode%20projects/Am-Project/packages/opencode/bin/opencode).
*   **Development Scripts in root `package.json`:**
    *   `bun run dev`: Runs the CLI in development mode (`packages/opencode/src/index.ts`).
    *   `bun run dev:desktop`: Runs the desktop application shell (`packages/desktop`).
    *   `bun run dev:web`: Starts the web UI development server (`packages/app`).
    *   `bun run dev:console`: Starts the console app developer server (`packages/console/app`).
    *   `bun run dev:stats`: Starts stats shell environment.
    *   `bun run dev:storybook`: Starts the terminal UI components storybook.

## 7. Install & Release Tooling

*   **Install Script:** [`install`](file:///home/n0face/Documents/Vscode%20projects/Am-Project/install) is a Shell script at the root directory that detects environment platform, system architecture, pulls release assets, and configures user shell paths.
*   **Release Automation:** Root scripts folder [`script/`](file:///home/n0face/Documents/Vscode%20projects/Am-Project/script) hosts deployment code:
    *   `publish.ts`: Monorepo deployment and publishing coordinator.
    *   `version.ts`: Package version updating script.
    *   `changelog.ts`: Commit parser and changelog generator.
*   **Build Compilation:** [`packages/opencode/script/build.ts`](file:///home/n0face/Documents/Vscode%20projects/Am-Project/packages/opencode/script/build.ts) compiles TypeScript bundles into target binary distributions and nests bundled Web UI assets within binaries.
